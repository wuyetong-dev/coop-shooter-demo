# 双人闯关 Demo · Co-op Run & Gun

一个**零依赖**的横版双人闯关射击 demo。两名角色（玩家 + AI 战友）同屏作战，纯 HTML5 Canvas 2D 实现——没有构建步骤，没有 npm，没有 node_modules。

打开即玩。

## 直接玩

- **单文件版**：双击 [`coop-demo.html`](coop-demo.html)（约 1.2 MB，脚本、立绘、音效全部内联，无需服务器）
- **多文件版**：浏览器打开 `coop-shooter-demo/index.html`（改代码后刷新即可看到效果）

## 操作

| 按键 | 动作 |
|---|---|
| `A` / `D` | 左右移动 |
| `W` / `空格` | 跳跃（支持二段跳） |

## 这个 demo 里有什么

不是"能跑就行"的骨架，几个地方做了真功夫：

**AI 战友的战术大脑**（`js/ai.js`）
三阶段决策循环：感知（子弹 / 敌人 / 补给）→ 评估（威胁打分）→ 执行（走位 / 躲弹 / 开火）。它会自己找掩体、卧倒架枪、跳过坑洞、上空中平台，被压制时会就地趴下。按 `Tab` 能看到它**实时的思考过程**——不是黑盒。

**姿态图而不是骨骼形变**（`js/chars.js`）
蹲和趴是各出一张专门立绘，不是在站姿图上硬压。原因写在代码注释里：立绘腿只占身高 26%，靠形变凑蹲姿怎么调都像"坐在看不见的椅子上"。定标时按**头盔宽度**缩放而非身高——按身高缩会把蹲姿撑成和站姿一样高，头宽是唯一不变的参照物。

**手感细节**
二段跳、冲刺缓冲、跨坑判定、擦身子弹的压制反馈、蹲行时双腿真的前后错开、爬行速度压到 38%。

**无损资源内联**
`build-single.js` 把 6 张干员立绘、姿态图、音效全部 base64 内联成单文件，产出发给谁都能直接双击打开。

## 项目结构

```
coop-shooter-demo/
├── index.html          # 多文件版入口
├── js/
│   ├── util.js         # 基础层：常量 / 工具 / 输入 / 音效
│   ├── chars.js        # 角色：立绘内联、姿态、物理尺寸
│   ├── ai.js           # AI 战友战术大脑 + 敌兵行为
│   ├── world.js        # 关卡、地形、平台
│   ├── game.js         # 主循环、状态机
│   ├── render.js       # 渲染层
│   ├── render2.js      # 渲染层（前景 / 特效 / 视差）
│   ├── hud.js          # HUD、战术面板、菜单
│   └── meta.js         # 元层：武器库、干员配置
├── art/                # 成品立绘（运行时不加载，已被内联）
├── tools/              # 素材处理工具链（抠图、定标、内联生成）
├── test/               # headless 回归测试 + 截图工具
└── build-single.js     # 单文件打包
```

## 开发

```bash
node test/headless.js     # 全量回归：26 项断言，0 失败
node test/menus.js        # 菜单层测试（改了 hud / meta 才需要）
node build-single.js      # 重新生成单文件版
node test/single-check.js # 从打包产物重跑关键链路
node test/shots.js        # 拍 12 张界面图，肉眼过一遍
```

改完代码的标准动作是这五步。少一步都可能留下"改了但玩家看不到"的状态。

## 美术与音效

角色立绘与场景由 AI 图像生成工具产出，再经 `tools/` 下的工具链处理（去棋盘格底、按头盔宽度定标、内联编码）。所有素材均为本 demo 自制。
